# Triage labels

The engineering skills use five canonical triage roles. This file maps those roles to this repository's GitHub labels.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate this issue. |
| `needs-info` | `needs-info` | The issue needs more reporter information. |
| `ready-for-agent` | `ready-for-agent` | The issue is ready for an agent. |
| `ready-for-human` | `ready-for-human` | The issue needs human implementation. |
| `wontfix` | `wontfix` | The issue will not be fixed. |

Use the GitHub label in the second column when a skill names a canonical role.
