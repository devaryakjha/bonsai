# Domain docs

This is a single-context repository.

Before code exploration, read these files when they exist:

- `CONTEXT.md` at the repository root.
- Related records in `docs/adr/`.

If these files do not exist, continue without comment. Create them only when a feature resolves a domain term or architectural decision.

Use the terms from `CONTEXT.md` in code, issues, specs, and test names. Flag a conflict with an ADR instead of silently overriding it.

## File structure

```text
/
├── CONTEXT.md
├── docs/adr/
└── src/
```
